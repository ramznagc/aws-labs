# 🐍 AWS Boto3 – Hands-on Lab

This hands-on lab introduces **Boto3**, the AWS SDK for Python.

The lab focuses on installing and configuring Boto3 and using Python scripts to interact with AWS services such as **Amazon S3** and **Amazon EC2**.

---

## 🎯 Learning Objectives

By completing this lab, I practiced:

- Installing Boto3
- Configuring AWS credentials
- Connecting Python applications to AWS
- Listing S3 buckets
- Creating an S3 bucket
- Uploading files to S3
- Launching EC2 instances
- Stopping EC2 instances
- Terminating EC2 instances
