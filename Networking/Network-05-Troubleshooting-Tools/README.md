# 🌐 Network Troubleshooting Tools

## 📖 Overview

This project documents the most commonly used Linux networking tools for troubleshooting connectivity, routing, DNS resolution, firewall issues, and service availability.

---

## Topics Covered

- Ping
- Traceroute
- MTR
- IP Address Commands
- ARP Cache
- DNS Troubleshooting
- Nmap
- Routing
- Telnet
- Curl
- SSH
- IPTables

---

## Learning Objectives

- Verify network connectivity
- Troubleshoot DNS issues
- Analyze routing paths
- Test TCP ports
- Inspect firewall rules
- Diagnose Linux networking problems
