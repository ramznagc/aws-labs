# ☁️ Amazon S3 - Static Website Hosting & Versioning

## 📖 Overview

This project demonstrates how to use Amazon S3 for object storage, static website hosting, bucket policies, and versioning.

The hands-on focuses on creating secure buckets, hosting static websites, configuring public access, and protecting objects with versioning.

---

## 🚀 AWS Services

- Amazon S3
- S3 Static Website Hosting
- Bucket Policies
- Object Versioning

---

## 🎯 Learning Objectives

- Create S3 buckets
- Upload and manage objects
- Configure bucket permissions
- Host a static website
- Configure bucket policies
- Enable versioning
- Restore deleted objects

## ✅ Key Takeaways

- Amazon S3 provides highly durable object storage.
- Static websites can be hosted directly from S3.
- Bucket policies control public access.
- Versioning protects against accidental deletion and overwrites.
