# ☁️ Amazon S3 Lifecycle Management & Bucket Replication

## 📖 Overview

This project demonstrates how Amazon S3 Lifecycle Management automates object transitions between storage classes and how Cross-Region Replication (CRR) improves availability and disaster recovery.

---

## AWS Services

- Amazon S3
- Lifecycle Rules
- Cross-Region Replication (CRR)
- IAM Roles

---

## Learning Objectives

- Create lifecycle rules
- Transition objects between storage classes
- Configure object expiration
- Configure Cross-Region Replication
- Create IAM roles for replication
- Test replication using prefixes and tags

## Key Takeaways

- Lifecycle rules reduce storage costs.
- Replication improves availability.
- IAM roles are required for bucket replication.
- Prefix and Tag filters provide selective replication.
