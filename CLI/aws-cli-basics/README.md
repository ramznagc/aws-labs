# ☁️ AWS CLI Basics

## Overview

This project introduces the AWS Command Line Interface (CLI), including installation, configuration, resource management, and automation using Amazon Linux 2023 AMIs.

---

## Topics Covered

- AWS CLI Installation
- AWS CLI Configuration
- IAM Commands
- Amazon S3 Commands
- Amazon EC2 Commands
- AWS Systems Manager Parameter Store
- Amazon Linux 2023 AMI

---

## Learning Objectives

- Install AWS CLI on different operating systems
- Configure AWS CLI credentials
- Manage AWS resources using CLI
- Launch EC2 instances from the command line
- Retrieve the latest Amazon Linux 2023 AMI
- Automate infrastructure tasks
